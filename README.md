
# Jogo da Forca

Jogo feito inteiramente em python, usando lista, biblioteca random, jogo com uma lógica simples, construida com ajuda do claude. Porém, todas as linhas de código foram construidas por mim e minha IDE com ajuda apenas do copilot.

- Sistema de erro que constroi uma parte do boneco a cada erro.
- Letras repetidas não são permitidas.
- Após o boneco ser inteiramente feito aparece mensagem de erro e o loop termina.
